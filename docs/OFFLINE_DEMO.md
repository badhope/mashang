# 离线演示步骤

这份步骤用来验证“断网也能学、能跑、能判题”，不靠口头说明。

## 准备

1. 安装 `mashang-v0.7.5.apk`，允许安装未知来源应用。
2. 首次打开后进入「课程」，随便点开一节 Python 课，确认页面能正常显示。
3. 打开手机飞行模式，同时关掉 Wi-Fi。

## 演示路径

1. 在课程页点「运行」，确认代码有输出，不会弹出网络错误。
2. 点「运行判题」，先故意写错一个变量，确认报错能指出哪一行、哪个断言没过。
3. 改对后再判一次，确认通过并加 XP。
4. 去「终端」执行 `print(1 + 1)`，确认 REPL 正常。
5. 去「挑战」，挑一道 Python 题，确认不联网也能判题。
6. 去「我的」里的「备份/恢复」，导出一份 JSON，确认文件落在 `Downloads/CodeLearning`。
7. 回到「课程」，确认刚才的进度还在。

## 预期结果

- 245 讲课程（含 JavaScript、TypeScript、C、Lua、SQL、DSA 与彩蛋）和 22 道挑战全程可用，不需要先下载课程包。
- 24 个课程包已随 APK 预装；飞行模式下从语言中心打开 JavaScript / SQL 课程也应能直接学习。
- 网页版不适用这条路径：它首次打开需要下载 Pyodide，之后靠浏览器缓存。

## 怎么证明不是云端判题

- 开飞行模式后仍然能运行和判题。
- 抓包看不到代码上传请求；应用只在你主动检查课程包更新或 App 版本时联网。
- 学习进度存在本机 DataStore，不上传服务器。

如果演示时任何一步依赖网络，说明这一版不能按“离线”宣传，应该先修再发。
