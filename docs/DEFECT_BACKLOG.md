## 这轮不当作缺陷的项

- 没有账号、云同步、社区、广告、统计 SDK：产品边界，不是漏做。
- 没有 iOS、只打 arm64-v8a：当前构建链和发布策略，写在 README 与质量报告。
- 没有 pip、多文件工程、自由项目：不和 Pydroid 抢手机 IDE 定位。
- 题库只有 22 道挑战：课程配套练习，不和 LeetCode 比题量。

## 验收口径

已修项必须有代码或文档落点，不能只在口头说明；待补项必须在 `PROJECT_BASELINE.md` 的任务池里保留，不能从清单里消失。
