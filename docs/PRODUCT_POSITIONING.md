# 产品定位与竞品对比

更新日期：2026-11-24

## 一句话

CodeLearning（码上）是一个装在安卓手机里的离线编程训练场：六门语言，边学边跑，assert 判题，错题自动进复习。

它不替代电脑上的 IDE，也不走视频课路线。核心是让没有稳定网络、只有碎片时间的人，掏出手机就能真的写代码、真的看到报错、真的被判题卡一下。

## 它不是什么

- 不是 Pydroid 那种自由 Python IDE，不主打 pip、第三方库和完整项目目录。
- 不是 SoloLearn、Mimo 那种以选择题、社区和职业路径为主的学习平台。
- 不是只读文档或视频课，所有练习都要求动手写代码。
- 不是云端判题器，不把用户代码发到服务器。

## 适合谁

- 零基础或刚入门，需要有人带着走完第一段路的人。
- 学生、通勤族、网络不稳定或流量有限的人。
- 低配安卓机用户，想要一个装完就能离线用的学习工具。
- 需要多语言语法对照的老师或自学者。

不适合：要写多文件项目、要装第三方库、要做数据分析或后端开发的人；需要 iOS、云同步、社区讨论的人；准备算法竞赛高阶题的人。

## 竞品对比

| 产品 | 他们强在哪 | 码上强在哪 | 码上的差距 |
| --- | --- | --- | --- |
| Pydroid 3 | Python IDE、pip、终端、文件操作 | 课程体系、判题、错题复习、六门语言 | 自由项目、第三方库生态、专业 IDE 能力 |
| SoloLearn / Mimo | 品牌、社区、游戏化、职业路径 | 代码在本机真跑、完全离线、六门语言 | 社区运营、内容包装、iOS 与多端覆盖 |
| 夜曲编程 / 编程狮 | 中文教研、课程运营、内容团队 | 真运行加判题、开源、无广告、数据本地 | 教研深度、视频和服务体系 |
| Replit / Colab | 云端算力、协作、项目生态 | 无网可用、轻量、隐私好 | 大项目、协作、云端环境 |
| LeetCode | 题库规模、竞赛社区 | 从讲到练到复习的完整链路、移动端离线 | 题目数量、难度上限、竞赛氛围 |

## 六门语言的真实边界

对外不能只写“六门语言”，要同时写清运行时边界，否则懂行的人一试就会觉得宣传和实际不符。

| 语言 | 运行时 | 边界 |
| --- | --- | --- |
| Python | Chaquopy 内嵌 CPython 3.13 | 真运行时；不预装第三方包，标准库可用范围受打包限制 |
| JavaScript | Mozilla Rhino 1.7.15 | 真解释器；ES 版本能力低于现代浏览器 |
| TypeScript | 类型擦除后交给 Rhino | 不做 tsc 类型检查，不支持装饰器、命名空间、条件类型 |
| C | Kotlin 写的教学子集解释器 | 不是 GCC/Clang，不支持预处理、goto、函数指针 |
| Lua | LuaJ 3.0.1 | 语义接近 Lua 5.2，不是完整 5.4 |
| SQL | SQLite 内存库 | 真 SQL 引擎，但不是 MySQL/PostgreSQL，不支持存储过程 |

## 竞争位置

综合能力不是全能冠军，属于细分品类里的强差异化产品：

- 课程广度中上，245 讲覆盖六门语言，每讲都有判题。
- 手机离线运行能力在同类学习产品里靠前，Python、JavaScript、SQL 是真实运行时。
- 学、练、判、复习的闭环完整，错题本和间隔复习是很多同类产品没有的。
- 品牌、社区、商业化是短板，短期内不可能靠规模赢。

所以对外应该打“离线编程学习”，不要打“手机 IDE”。打 IDE 会被拿去和 Pydroid 比装库和项目目录，反而吃亏。

## 下一步优先级

1. 内容深度：先把 Python 进阶、综合项目、SQL 实战做深，不再增加语言数量。
2. 可信证明：公开课程样例、判题用例、离线演示、版本记录和测试结果，降低“自说自话”的感觉。
3. 移动端体验：首屏到第一节课的路径、课程完成率、低端机帧率，这些比再加功能更能决定留存。
4. 多文件项目是产品形态问题，不是再加几道题能解决的；在没想清楚编辑器交互前不要硬上。
