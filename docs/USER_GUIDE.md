# CodeLearning · 码上 用户手册

> 适用于 v0.7.1（versionCode 20）及后续版本。  
> 项目主页：<https://gitcode.com/badhope/mashang>  
> 官网：<https://badhope.github.io/mashang/>

CodeLearning（码上）是一台装在手机里的离线编程学习终端：课程、代码编辑器、真实语言运行时和断言判题都在本机运行，不需要账号，也不会上传学习数据。

---

## 1. 支持范围

| 项目 | 要求 |
|---|---|
| 系统 | Android 10（API 29）及以上 |
| 处理器 | arm64-v8a |
| 存储 | 首装约 39 MB；语言包按需下载 |
| 网络 | 非必需；仅下载语言包和检查更新时使用 |

内置六门语言运行时：

| 语言 | 运行时 | 课程 |
|---|---|---|
| Python | CPython 3.13 | 39 讲主线 + 综合项目 + DSA + 彩蛋 |
| JavaScript | Rhino 1.7.15 | 38 讲，四个课程包 |
| TypeScript | 类型擦除后复用 Rhino | 38 讲，四个课程包 |
| C | Kotlin 教学子集解释器 | 38 讲，四个课程包 |
| Lua | LuaJ 3.0.1 | 38 讲，四个课程包 |
| SQL | SQLite 内存库 | 43 讲，含 5 讲边界专题 |

C / TypeScript 是教学子集：C 不支持预处理指令、`goto` 与函数指针；TypeScript 不支持装饰器与命名空间。遇到不支持的语法会明确报错，不会静默给出错误结果。Java / C++ / Go / Rust 需要完整编译器或原生工具链，当前不提供，也不设下载入口。

## 2. 下载与安装

从任一官方 Release 下载 `mashang-v0.7.1.apk`：

- GitHub：<https://github.com/badhope/mashang/releases/latest>
- GitCode：<https://gitcode.com/badhope/mashang/releases>
- Gitee：<https://gitee.com/badhope/mashang/releases>

安装步骤：

1. 下载 APK 到手机。
2. 在系统设置中允许当前文件管理器/浏览器「安装未知来源应用」。
3. 点击 APK，确认安装。
4. 首次启动会展示隐私说明；同意后进入初始化，随后进入课程页。

> 只从上述官方仓库下载。第三方网盘转存的 APK 可能被替换，应用内「关于」页的版本号与签名无法自证。

### 从源码构建

```bash
./gradlew :app:assembleDebug
```

正式签名构建需要环境变量 `KEYSTORE_PATH`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`，具体见 `.github/workflows/ci.yml`。

## 3. 首次启动

1. 阅读隐私政策与用户协议。
2. 同意后，应用在本地初始化 Python 运行时；首次初始化需要几秒。
3. 进入「课程」页，从第一幕第一课开始。

不需要注册、登录、手机号或邮箱。应用没有广告 SDK、统计 SDK 和云端判题。

## 4. 60 秒上手

1. **选课**：课程按章节渐进解锁，通过当前课才能进入下一课。
2. **读课**：每讲由讲解、可运行代码、输出预览、图示、测验等块组成。
3. **运行代码**：代码块右上角「运行」在本机执行，返回标准输出、错误、耗时与变量快照。
4. **做练习**：页面底部「实战演练」写代码，点「运行判题」。
5. **看结果**：通过得 XP 并解锁下一课；失败会逐条显示哪个断言没过，并自动进入错题本。
6. **随时试**：底部「终端」是 REPL，适合验证小片段；输入多行块时以空行结束。

### 变量快照

每次运行后可以查看当前命名空间里的变量名、类型和值。它展示的是真实执行后的内存状态，不是预设答案。超长值会被截断，超大对象会被跳过，避免拖垮界面。

### 判题规则

- 练习由若干条 `assert` 组成，必须全部通过。
- 多条测试共享同一份用户命名空间副本，但不会污染你定义的变量。
- 死循环有超时保护，会中断并返回 `Timeout`。
- 判题失败不会扣 XP，只记录错题。

## 5. 语言中心与离线课程包

路径：`我的 → 语言中心`。

- Python 主线随 APK 内置，断网可学。
- JavaScript / TypeScript / C / Lua / SQL 以及 DSA、彩蛋课按需下载。
- 每个包下载后会做 SHA-256 校验，校验失败不会落地。
- 已下载的包完全离线可用；卸载应用会一起删除。
- 语言包下载失败时，界面会显示「已装 X/Y 包」和失败原因，可重试。

如果所在网络访问 GitHub 较慢，内容中心会按 GitCode → GitHub raw → GitHub Pages 的顺序回退，单源超时 4 秒。

## 6. 挑战、错题与复习

- **挑战**：22 道独立题，六门语言都有；每题 5–8 条判题，不依赖课程进度。
- **错题本**：判题失败自动记录题目、你的代码、错误信息和失败次数，可一键跳回重做。
- **复习台**：按 SM-2 变体生成复习卡，按记忆质量调整下次复习间隔。
- **连击 / XP / 徽章**：完成课程与挑战累积 XP；连续学习形成连击；徽章只增不减。

## 7. 备份、恢复与换机

路径：`我的 → 备份/恢复`。

- **导出**：生成 JSON 到 `Downloads/CodeLearning`，包含 XP、通关课程、已解练习、连击、徽章、错题与复习卡。
- **导入**：在文件选择器中选择备份 JSON；导入前会校验版本与结构。
- **换机**：旧机导出 → 把 JSON 传到新机 → 新机导入。
- **注意**：重置进度不可撤销；重置前请先导出备份。

备份只包含学习数据，不包含账号、设备标识或通讯录。

## 8. 权限与隐私

| 权限 | 用途 |
|---|---|
| `INTERNET` | 下载语言包、检查更新 |
| `ACCESS_NETWORK_STATE` | 判断当前是否联网，给出可读提示 |

应用不申请存储读写权限：导出备份走 MediaStore / 系统文件选择器。没有位置、相机、麦克风、通讯录、短信权限。

- 没有账号体系；
- 没有埋点、广告、统计 SDK；
- 不上传代码、学习记录或错题；
- 卸载即删除本地数据（系统备份除外）。

完整条款见 [隐私政策](../PRIVACY_POLICY.md) 与 [用户协议](../TERMS_OF_SERVICE.md)。

## 9. 检查更新

路径：`我的 → 系统设置 → 检查更新`。

应用只读取 GitHub Releases 的公开版本号，不自动下载 APK、不申请安装权限。发现新版本时点「打开发布页」，在浏览器下载后覆盖安装；学习数据不会丢失，仍建议先备份。

如果提示「网络不可用或无发布记录」，不影响离线学习。

## 10. 常见故障

| 现象 | 处理 |
|---|---|
| 安装被拦截 | 在系统设置允许该来源安装；确认下载的是 arm64 包 |
| 首次启动停在初始化 | 强制停止后重开；确认剩余存储 ≥ 200 MB |
| 语言包下载失败 | 切换 Wi-Fi/移动网络，回语言中心重试；已装包不受影响 |
| 判题一直转圈 | 代码可能有死循环，等待超时中断；简化循环条件 |
| 判题说变量不存在 | 检查变量名拼写、作用域，以及是否在函数里定义却没返回 |
| 终端多行不执行 | 多行块以空行结束；REPL 与课程练习不共享命名空间 |
| 备份导入失败 | 确认是本应用导出的 JSON、版本未损坏；重新导出再试 |
| 更新后打不开 | 从官方 Release 重新下载覆盖安装；先备份数据 |
| 网页版打不开 | 网页版需首次加载 Pyodide（约 12 MB），网络受限时改用 App |

仍无法解决时，带上「我的 → 诊断」里的版本、机型和错误信息，到仓库提 issue。
