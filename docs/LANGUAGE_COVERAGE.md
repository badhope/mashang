## 先回答两个问题

**支持很多语言吗？** 支持六门，且都是真运行时，不是占位：

`Python`（CPython 3.13，随 APK 内置）、`JavaScript`（Rhino 1.7.15）、
`TypeScript`（类型擦除后复用 Rhino）、`C`（纯 Kotlin 教学子集解释器）、
`Lua`（LuaJ 3.0.1）、`SQL`（SQLite 内存库）。

但「很多」到此为止。Java / C++ / Go / Rust 只在 `LanguageIds.PLANNED` 里列出，
没有运行时、没有课程，语言中心会显示「暂不支持」。六门之外不要对外承诺。

**题目足以支持很多语言吗？** 每讲都有判题，平均 3.94 道用例；够做入门练习和
课后复习，**不够支撑「精通」或项目实战**。六门都已有一个综合项目课，但项目规模
仍是单文件、单表级别，不是可交付的系统。

## 真实强弱

- **每讲都有题**：245 讲 `exercise.tests` 全部非空，没有「只读不练」的课。
- **JavaScript / TypeScript / Lua 题量最稳**：每讲 4–5 道为主，均值 4.2–4.5。
- **TypeScript 示例密度已补齐**：38 讲 76 个可运行示例，每讲正好 2 个；`practice`
  卡片现在可以点「运行这段示例」，不再是只读代码。
- **SQL 仍是最薄的一门**：43 讲平均 3.12 道，大量断言仍是 `columns` / `rows` /
  `len`；5 讲边界专题已覆盖 NULL 分组、重复行、排序并列、事务回滚与复合索引
  左前缀，但深度仍低于其他五门。
- **C 偏薄**：解释器是教学子集（无预处理、goto、函数指针），题量受运行时边界限制。
- **综合项目已覆盖六门**：Python 记账本、JS/TS 各自的综合项目、C 成绩管理、
  Lua 背包结算、SQL 漏斗留存；都还是单课练习，不是多文件工程。
- **挑战题已拉齐到 5–8 例**：22 道挑战全部不少于 5 例；六道综合挑战各 8 例，
  Python 用双函数 + 双排序规则，JS/TS/C/Lua 用双函数边界，SQL 用双表 JOIN。
